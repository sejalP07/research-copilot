# Research Copilot

AI-powered research assistant that can:

- Search the web using Tavily
- Retrieve knowledge from uploaded documents
- Generate cited answers
- Perform multi-step research
- Use LangGraph for agent orchestration

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend
- FastAPI
- LangGraph
- LangChain

### AI
- OpenAI
- Tavily Search
- FAISS
- Hybrid RAG

## Status

🚧 Currently in development

## Features

- Gemini AI powered research assistant
- Tavily web search integration
- PDF document upload
- Retrieval Augmented Generation (RAG)
- Supabase cloud storage and database
- Research history tracking
- Source citations and confidence scoring
