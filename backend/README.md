# Research Copilot

AI-powered research assistant that can:

- Search the web using Tavily
- Retrieve knowledge from uploaded documents
- Generate cited answers
- Perform multi-step research
- Use LangGraph for agent orchestration

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend
- FastAPI
- LangGraph
- LangChain

### AI
- OpenAI
- Tavily Search
- FAISS
- Hybrid RAG
